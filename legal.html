Privacy e GDPR

Simule è un'applicazione web statica che funziona interamente nel browser dell'utente. Non raccogliamo, non archiviamo e non trasmettiamo dati personali a server propri.

Dati trattati

Simule non dispone di account utente, moduli di registrazione o sistemi di autenticazione. Non è presente alcun backend proprietario. I dati che l'applicazione gestisce sono:

  • File GPX / TCX / KML: elaborati esclusivamente in memoria nel browser (lato client). Non vengono mai trasmessi a server Simule.
  • Preferenze utente (altezza, lunghezza del passo, impostazioni di simulazione): salvate in localStorage del browser, sul dispositivo dell'utente, senza sincronizzazione remota.
  • Percorsi recenti e catalogo contributi utente: memorizzati in localStorage, accessibili solo dal browser locale.

Base giuridica

Non essendo raccolti dati personali identificabili, non sussiste un trattamento ai sensi del Regolamento UE 2016/679 (GDPR) da parte del titolare del sito. L'utente controlla interamente i propri dati locali.

Diritti dell'utente

Poiché tutti i dati risiedono sul dispositivo dell'utente, l'utente può in qualsiasi momento:

  • cancellare i dati di Simule svuotando il localStorage del browser (o usando il pulsante "Svuota percorsi recenti" nelle Impostazioni);
  • revocare l'accesso a sensori (Bluetooth, GPS) dalle impostazioni del browser/sistema operativo.

Contatto

Per qualsiasi domanda: github.com/ciao-madesign/simule/issues.

Cookie e localStorage

Simule non usa cookie propri di nessun tipo (tecnici, analitici o di profilazione).

L'applicazione utilizza esclusivamente il localStorage del browser (API Web Storage) per mantenere le preferenze dell'utente tra una sessione e l'altra. Il localStorage è una memoria locale al dispositivo: nessun dato viene inviato a server e non è accessibile da altri siti.

I servizi di terze parti integrati (YouTube, Mapillary, ecc.) possono impostare propri cookie quando vengono attivati dall'utente. Si rimanda alle rispettive informative. Simule non ha controllo su tali cookie.

Avviso sui dati personali nei file GPX

I file GPX registrati da smartwatch, GPS da polso o applicazioni di tracciamento (Garmin, Strava, Wahoo, ecc.) possono contenere dati personali, tra cui:

  • il luogo di abitazione (punto di partenza/arrivo frequente);
  • luoghi di lavoro, palestre, scuole e altri punti di interesse personale;
  • orari abituali e pattern comportamentali deducibili dalla frequenza delle registrazioni;
  • dati biometrici (frequenza cardiaca, cadenza) se esportati con il tracciato.

Uso privato (caricamento personale): il file viene elaborato esclusivamente in memoria nel tuo browser e non lascia mai il tuo dispositivo. Simule non vede né conserva questi dati.

Contribuzione al catalogo pubblico: prima di condividere un tracciato, ti raccomandiamo di:

  • rimuovere i primi e ultimi punti che si avvicinano alla tua abitazione;
  • usare strumenti come GPS Visualizer o la funzione "Privacy Zone" di Strava per oscurare i punti sensibili;
  • verificare l'assenza di dati biometrici nel file prima di caricarlo.

Simule non si assume alcuna responsabilità per i dati personali contenuti nei file GPX caricati o condivisi dagli utenti. La responsabilità della verifica e dell'anonimizzazione dei dati è esclusivamente dell'utente che contribuisce.
